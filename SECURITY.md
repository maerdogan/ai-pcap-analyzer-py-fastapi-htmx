# Security

## Report a problem

Use **Report a vulnerability** on this repository's Security tab, which keeps the report private. Do not open a public issue.

Include the version, how you installed it and the steps to reproduce. Do not attach real captures or keys. They can hold customer data, so make a small sample instead.

## Supported versions

Only the latest release gets fixes.

## What the application does not cover

The README lists what the person who installs it must add, such as HTTPS, network limits and retention.
